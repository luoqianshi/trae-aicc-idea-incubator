# 在上传模板文件后、粘贴此提示词前，请先用键盘输入： /brainstorming 我准备参加TRAE AI创造力大赛，以上是TRAE AI创造力大赛的报名贴发帖模板，我想请你和我不断交互梳理我的参赛选题，并最终将和我讨论的过程按该模板的格式梳理为可以直接一键粘贴复制发表的推文。 以下是我的一些初步的想法： [在这里尽情描述你的灵感，尽量描述你观察到的痛点、想服务的对象、以及你设想的产品形态]
STEP 01

安装技能

首次使用 TRAE Work，前往左上角的【技能模块】，在【技能市场】的【效率提升】分类中安装 brainstorming 技能

安装一次即可永久使用，这是灵感梳理的核心引擎
STEP 02

上传模板

将大赛官方的报名发文模板 .md 文件拖入 TRAE Work 对话窗口，让 AI 理解输出格式要求

模板文件包含标题、标签、正文四部分的格式规范
STEP 03

启用技能

在粘贴提示词之前，输入 Use Skill: brainstorming 显式启用技能

这会激活 AI 引导式发问功能，结合模板逐步梳理你的灵感
STEP 04

粘贴提示词

复制上方提示词模板，填入你自己的灵感关键词后发送给 TRAE Work

关键词越具体，AI 引导的方向越精准
" brainstorming 技能会激活 TRAE AI 的引导式发问功能，结合报名模板以提问和给出建议方案的方式，引导你逐步把灵感沉淀为标准的报名帖。 "
— 灵感孵化舱 · 播种阶段
02

浇灌。多轮对话迭代

iterate.with.ai

与 AI 深度对话

通过 5-10 轮结构化交互，将模糊灵感打磨为清晰方案

Round 1

确认赛道与方向

TRAE Work 会询问你想参加的赛道（生活娱乐 / 学习工作 / 社会服务 / 硬件交互），以及你的核心创意方向。如实回答，AI 会帮你定位。

Round 2

细化目标用户与痛点

AI 会追问：你的产品面向谁？他们在什么场景下使用？没有你的产品他们会遇到什么不便？这些问题帮你找到产品的真实价值锚点。

Round 3

确定产品形态

App、小程序、网站、系统还是硬件？AI 会根据你的描述推荐最合适的产品形态，并给出理由。

Round 4

梳理价值与意义

从商业价值、效率提升、社会价值中选取角度，AI 会帮你把模糊的"我觉得有用"转化为有说服力的价值论述。

Round 5

生成报名帖草稿

所有信息收集完毕后，TRAE Work 会按照模板格式自动生成完整的报名帖文本，你可以直接复制粘贴发布。

" 在 TRAE Work 的引导下，根据 TRAE Work 的提问和提案做选择题并修正，直到初步打磨出一个灵感产品的雏形。 "
— 灵感孵化舱 · 浇灌阶段
03

修剪。整理产品思路

shape.the.idea

从碎片到结构化方案

将对话中沉淀的信息整理为清晰的产品框架

创意名称

一个简洁有力的名字，让人一眼就知道你要做什么

目标用户

精准定义你的核心用户群体和使用场景

产品形态

App / 小程序 / 网站 / 系统 / 硬件，选择最合适的载体

核心痛点

没有你的产品，用户现在会遇到什么不方便

价值与意义

从商业价值、效率提升、社会价值中选取角度论述

HTML Demo

用互动页面展示你的创意，让评审直观感受产品愿景

04

绽放。生成你的作品

ship.the.demo

从方案到可交付作品

用 TRAE 的前端生成能力，把文字方案变成有设计感的互动页面

报名帖的最后一个要求是附带 TRAE Work 生成的 HTML 文件。这一步，你需要让 TRAE 使用前端生成SKILL，配合你喜欢的前端风格模板或者提示词，将你的创意方案转化为一个视觉精美的互动 Demo 页面。

frontend-design
frontend-skill

以上是 TRAE 内置的前端生成相关技能。你也可以让 TRAE 从 GitHub 代码仓库中寻找合适的前端框架或组件库作为参考。

推荐 GitHub 优质前端设计技能：

huashu-design npx skills add alchaincyf/huashu-design taste-skill npx skills add https://github.com/Leonxlnx/taste-skill

推荐风格化提示词模板网站：

DesignPrompts.dev 选择你喜欢的前端风格提示词模板
PROMPT 绽放提示词 · 生成 HTML Demo
# 使用 frontend-design 技能生成 Demo： /frontend-design 请使用 frontend-design 技能，根据我们刚才整理的创意方案，生成一个单文件 HTML 互动 Demo 页面。 要求： - 页面要能直观展示我的产品创意和核心功能 - 使用 我所上传的网页设计提示词风格【Organic.md】 # 可以根据喜好上传自己喜欢的前端风格的提示词模板 - 包含产品介绍、核心功能展示、用户场景模拟等模块 - 响应式设计，手机和电脑上都能良好展示 - 所有代码写在一个 HTML 文件中，可以直接在浏览器打开
