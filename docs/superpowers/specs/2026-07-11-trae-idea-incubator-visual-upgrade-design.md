# TRAE 灵感孵化舱 · 视觉与交互升级设计文档

**日期：** 2026-07-11  
**主题：** 在保留 TRAE 官方元素的基础上，对现有单页指南进行高级感视觉升级与游戏化交互引导改造。  
**状态：** 待实施（设计已确认）

---

## 1. 项目背景

现有站点 `index.html` 是一份面向 TRAE AI 创造力大赛参赛者的四步操作指南，采用暗色背景 + 品牌绿（`#22c55e`）的 TRAE 风格。用户希望：

1. 在保留 TRAE 官方元素的前提下提升视觉高级感。
2. 重新设计更有质感的 Hero 板块，并新增两个外部入口 CTA。
3. 把“指南式”内容升级为“角色任务化 + 对话气泡 + 选择卡片”的游戏化交互体验。

---

## 2. 目标

- 让页面看起来更像“高端产品发布/任务中心”，而非普通文档。
- 保留并强化 TRAE 品牌识别（logo、绿色、阶段命名、现有按钮文案/功能）。
- 通过任务追踪器、对话气泡与可点击选择卡片，引导用户按四步完成从灵感到投稿的流程。
- 保证移动端、键盘与减少动效偏好下的可用性。

## 4. 视觉方向

**定调：** 电影感暗色编辑风 + 克制科技光效。

- **背景：** `#050505` 极黑画布，叠加低透明度绿色极光径向渐变，保留并升级粒子网络（更大的节点、更柔和连线、鼠标排斥）。
- **字体：**
  - 标题/Display：`Bricolage Grotesque`（Google Fonts），几何感强、有张力。
  - 正文：继续使用系统无衬线 / Inter，保证可读性。
  - 等宽：保留 JetBrains Mono 用于提示词代码块。
- **卡片：** 玻璃质感 `rgba(255,255,255,0.03)` + 1px 边框 `rgba(255,255,255,0.08)` + `backdrop-filter: blur(20px)`，圆角 20–24px。
- **按钮：** pill 形状；主按钮保持 `#22c55e` 黑字；次按钮透明边框；悬停发绿光。
- **强调：** 保留 `#22c55e`，新增 `#a3e635` 用于完成态、高亮与悬停光晕。

## 6. 导航与任务追踪

### 桌面端
- 固定顶部导航栏：左侧 logo + 站点名，右侧“大赛官网”。

- 左侧垂直追踪器隐藏，改为顶部固定横向进度条（或折叠为底部小条）：
  - 显示当前阶段编号与名称，左右箭头可切换。
  - 进度条随滚动填充。

## 7. 任务关卡式内容区

每个阶段（section）重构成一次“任务对话”：

1. **TRAE Work 开场气泡**
   - 左侧显示 `assets/trae_dark.png` 作为头像。
   - 气泡内用第一/二人称发布当前阶段任务，例如：
     > “欢迎来到灵感孵化舱。第一步，下载模板并开启 brainstorming 技能。”
   - 气泡使用玻璃卡片，尾指向头像。

2. **选择卡片组**
   - 把原本指南中的关键动作（下载模板、安装技能、复制提示词、查看截图等）变成可点击卡片。
   - 每个卡片包含：SVG 图标 + 动作名称。
   - 点击后执行对应动作：
     - 下载：触发 `downloadTemplate()`。
     - 复制：触发 `copyPrompt()`。
     - 外链：打开新标签页。
     - 展开详情：显示对应的提示词面板/步骤卡片/时间线。
   - 已点击的卡片标记为完成（绿色边框 + ✓），状态持久化到 `localStorage`。

3. **用户反馈气泡（可选）**
   - 点击某个选择卡片后，出现一句用户侧气泡，例如：
     > “已复制提示词，准备粘贴到 TRAE Work。”
   - 仅用于仪式感，不做复杂分支。

4. **任务详情面板**
   - 保留现有内容：提示词卡片、步骤卡片、时间线、结果展示、引用块等。
   - 统一升级为玻璃卡片风格，但内容结构不变。

## 8. 交互与动效

### 入场动效
- 导航栏从顶部滑入（`translateY(-100%) → 0`）。
- Hero 标题逐行淡入上移（stagger 0.1s）。
- CTA 按钮依次缩放出现（stagger 0.08s）。
- 粒子背景淡入。

### 滚动动效
- 每个 section 进入视口时整体 `opacity 0 → 1` + `translateY(24px → 0)`。
- 内部卡片按顺序 stagger 出现。
- 任务追踪器高亮随滚动自动切换。

### 微交互
- 选择卡片悬停：上浮 4px + 边框发绿光 + 阴影。
- 选择卡片点击：涟漪或缩放反馈，变为完成态（绿色边框 + ✓）。
- TRAE 对话气泡进入视口时从左侧滑入淡入。
- 模态框淡入 + 轻微缩放；按 `Esc` 关闭。

### 减少动效
- 遵循 `prefers-reduced-motion`：
  - 关闭 stagger、打字机、粒子动画。
  - 所有过渡变为 `0s` 或极短。

## 9. 响应式与无障碍

### 响应式
- **桌面（>1024px）：** 左侧固定任务追踪器，右侧内容区；Hero 标题 64px 左右。
- **平板（768–1024px）：** 任务追踪器变为顶部横向；内容区保持双列展示结果卡片。
- **移动（<768px）：** 顶部横向进度条；Hero 标题缩小；选择卡片单列全宽；对话框全宽。

### 无障碍
- 所有选择卡片使用 `<button>` 或 `role="button"`，支持 `Enter` / `Space` 触发。
- 焦点样式可见：绿色 outline 或 box-shadow。
- 使用 `aria-current="step"` 标记当前任务。
- 模态框使用 `role="dialog"` + `aria-modal="true"`，关闭按钮有 `aria-label`。
- 颜色对比满足 WCAG AA：正文 `#d4d4d8` 及以上，绿色在深色背景上保持清晰。

## 10. 错误处理与降级

- **localStorage 不可用**（隐私模式/禁用）：捕获异常，不持久化完成状态，交互仍可正常使用。
- **剪贴板复制失败**：提示“请手动复制”。
- **图片资源缺失**：保留 `alt` 文本，头像缺失时显示 TRAE 首字母占位。
- **Canvas 不支持**：回退为静态渐变背景，不影响核心功能。
- **外部链接无法访问**：由浏览器处理，不做额外拦截。

## 12. 不在本次范围内

- 不改动大赛官方报名模板文件的内容与下载逻辑。
- 不做复杂分支剧情或多结局状态机；选择卡片仅触发单步动作与完成标记。
- 不引入后端、构建工具或框架；仍保持单文件 HTML + CSS + JS。
- 不替换现有所有图片资源，仅对样式与交互进行改造。

## 13. 决策记录

| 决策 | 选项 | 选定 | 原因 |
|---|---|---|---|
| 视觉方向 | A 电影感 / B 霓虹实验室 / C 有机生长 | A + B 混搭 | 既有高端编辑感，又保留科技光效 |
| 交互形式 | 步骤条 / 任务清单 / 聊天 / 角色任务化 | 角色任务化 + 对话气泡 + 选择卡片 | 最符合用户想要的仪式感，且实现可控 |
| 方案范围 | 全页改造 / Hero + 保留指南 / 悬浮助手 | 沉浸式单页冒险（全页改造） | 统一感最强，整体高级 |
| 图标 | emoji / SVG | SVG | 用户明确要求 |
| TRAE 头像 | 文字 / 品牌 logo | `assets/trae_dark.png` | 用户指定 |
